🤖 ShortsBot

App personal para controlar el bot que crea y sube Shorts de curiosidades de Minecraft a mi canal. Tus datos están en tu repositorio privado de GitHub; esta página solo los lee con tu clave, que se guarda en este dispositivo.

Conecta la app (una vez por dispositivo)

  1. Abre GitHub → Crear clave (fine-grained token).
  2. Nombre: ShortsBot app. Caducidad: la más larga que te deje.
  3. Repository access → Only select repositories → elige shortsbot.
  4. Permissions → Actions: Read and write y Contents: Read and write.
  5. Pulsa Generate token, cópialo y pégalo aquí:
